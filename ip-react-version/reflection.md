I built an IP Address Tracker with React. You type an IP address(specific format where the 4 sections must be seperated by a period eg: 8.8.8.8 ), and the app shows the location, timezone, ISP, and a map. I used a Header, a Main page, a custom useFetch hook, the ipify API, and Leaflet for the map. My first big problem was the error “Cannot read properties of undefined (reading ‘city’).” React draws the page before the API data arrives, so Main tried to show a city that wasn’t there yet. I fixed it by adding an if (!ipInfo) check that waits for the data.My second problem was where to put the fetch. Header and Main are siblings, so they can’t share data directly. I learned to put the fetch in App, the parent. Header sends the search word up with onSearch, and App sends the answer down to Main. I also learned that hooks can’t be used inside a normal function like geoInfo. Other problems were smaller. Leaflet’s L was not defined until I loaded the library. The API gave a 403 error because I never exported and imported my key from config.js. The map was slow because I rebuilt it on every search. To fix that, I now build the map one time and only move it when new data arrives.
If I had more time, I would improve a few things. I would show a clear error message when something fails, shrink the header image so the page loads faster and remove the strict rule for when you enter the ip address.

ReadMe.md

 Type an IP address in the search box and press the button or Enter. An IP address has 4 sections separated by dots, like 8.8.8.8. Each section must be a number from 0 to 255, and the dots are required or it will not work. The dots tell the computer where one number ends and the next one starts, so without them 8888 could mean many different addresses. Each section is stored in 8 bits, and 8 bits can only count up to 255, so a number like 300 does not fit. This app searches by IP address, so a website name like google.com may not work yet.
